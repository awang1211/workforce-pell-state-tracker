# Methodology

## Research questions

The tracker asks:
1. What implementation stage has the state reached?
2. What evidence supports that classification?
3. What materially changed over time?
4. Which programs have received approval, and at what level?
5. Can students actually access Workforce Pell yet?
6. What data, governance, or institutional-capacity constraints explain differences across states?

## Source hierarchy

Preferred order:
1. U.S. Department of Education / Federal Student Aid
2. Governor or official state agency
3. State higher-education/workforce agency
4. Institution announcement
5. High-quality sector publication
6. Secondary commentary

## Approval funnel

The tracker distinguishes:

`potential program → redesign → state application → state approval → federal approval → enrollment → Pell disbursement → completion → Q2 employment → occupation match → earnings`

These are separate milestones.

## Federal approval evidence

Federal approval records preserve their evidence source, for example:
- `ED announcement`
- `State official roster`
- `Institution announcement`

When a state official roster says a program is federally approved but no ED announcement is found, the program may be included in a public-record total while retaining a verification flag.

## Date methodology

Dates are not interchangeable:
- event date
- effective date
- source publication date
- detected date

If the exact approval date is not published, do not infer one from the date the tracker discovered the source.
